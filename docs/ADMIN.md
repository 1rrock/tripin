# Tripin — 어드민 화면기획

> 콘텐츠 원가가 곧 제품 원가다. **어드민 속도가 곧 서비스 확장 속도다.**
> 선행 문서: `CONCEPT.md`(제품) · `INGEST.md`(파이프라인) · `LEGAL.md`(제약) · `docs/DATABASE.md`(스키마)

---

## 0. 이 화면들이 지켜야 하는 단 하나의 숫자

**확정 1건당 10초.**

조각 하나가 12핀이면 확정에 2분. 이 숫자가 무너지면 월 8~12조각이라는 생산 계획 전체가 무너진다.
그래서 `/admin/confirm` 은 **마우스 없이 키보드만으로 연속 처리**되도록 설계한다. 나머지 화면은 이 화면을 위한 부속이다.

## 1. 인증 — 비밀번호 1개 + httpOnly 쿠키

혼자 쓰는 사이드 프로젝트이므로 계정 체계를 두지 않는다.

```
/admin/login   비밀번호 입력
     ↓ POST /api/admin/login
서버에서 ADMIN_SECRET 과 비교 (타이밍 안전 비교)
     ↓ 성공
httpOnly · secure · sameSite=lax 쿠키 발급 (서명값, 7일 만료)
     ↓
proxy(middleware) 가 /admin/* 과 /api/admin/* 전부 검사
```

### 규칙

| 항목 | 결정 |
|------|------|
| 쿠키 값 | 비밀번호를 그대로 넣지 않는다. `HMAC-SHA256(ADMIN_SECRET, exp)` + `exp` 형태의 서명 토큰 |
| 쿠키 속성 | `httpOnly` `sameSite=lax` `path=/`, 프로덕션에서 `secure` |
| 만료 | 7일. 재로그인 부담과 노출 위험의 절충 |
| 비교 | `crypto.timingSafeEqual` — 문자열 `===` 금지(타이밍 공격) |
| 실패 제한 | 같은 IP 5회 실패 시 60초 잠금 (메모리 카운터로 충분) |
| 로그아웃 | `/api/admin/logout` — 쿠키 만료 |
| `ADMIN_SECRET` 미설정 시 | **프로덕션에서는 `/admin/*` 전체를 404** 로 막는다. 빈 비밀번호로 열리는 사고 방지 |

### robots

`/admin/*` 은 `robots.txt` 에서 차단하고 페이지에 `noindex` 를 단다. 색인되면 안 된다.

## 2. 전체 흐름과 상태 전이

```
  ┌─ /admin/ingest ─────────────────────────────┐
  │  채널 선택 or URL 입력 → 영상 목록           │
  │  → 자막 추출 → LLM 분석 → 후보 생성          │
  └──────────────┬──────────────────────────────┘
                 │  후보(메모리, 미저장)
                 ▼
  ┌─ /admin/confirm ────────────────────────────┐
  │  후보를 하나씩 넘기며 판정                    │
  └──┬────────────┬────────────┬────────────────┘
     │확정         │보류         │버림
     ▼            ▼            ▼
  place        place        폐기
  confirmed    candidate   (저장 안 함)
     │
     ▼
  ┌─ /admin/place/[id] ─────────────────────────┐
  │  요약문 작성 (3~5불릿)                       │
  └──────────────┬──────────────────────────────┘
                 ▼
  ┌─ /admin/publish ────────────────────────────┐
  │  조각(채널×도시) 단위 체크리스트 통과 → 공개  │
  └─────────────────────────────────────────────┘
```

**핵심**: 후보는 확정 전까지 **DB에 없다.** 메모리(세션)에만 있다가 확정 시점에 `places` 행이 생긴다. 버린 후보는 흔적을 남기지 않는다.

## 4. `/admin/ingest` — 영상 넣기

```
┌──────────────────────────────────────────────┐
│ ← 대시보드                                     │
├──────────────────────────────────────────────┤
│ 대상                                           │
│  ○ 채널에서 고르기  [추성훈 ▾]                 │
│  ● URL 직접 입력    [youtube.com/watch?v=…  ] │
│                                               │
│  도시  [도쿄 ▾]   ← 조각 단위 지정             │
├──────────────────────────────────────────────┤
│ 영상 목록  (playlistItems.list · 1 unit)      │
│  ☑ 워뇨 추천 도쿄 돈카츠      2026-06-12  18:42│
│  ☑ 도쿄 3박4일 먹방          2026-05-30  22:10│
│  ☐ 쇼츠 - 이거 뭐임          2026-05-28   0:48│ ← 쇼츠 자동 해제
│  ☐ 브이로그 (여행 아님)      2026-05-20  12:03│ ← LLM 판정 제외
│                                               │
│  선택 2개              [분석 시작]             │
├──────────────────────────────────────────────┤
│ 진행                                           │
│  ✔ 자막 추출     2/2                          │
│  ⟳ 장소 분석     1/2                          │
│  ○ 지도 매칭     0/2                          │
└──────────────────────────────────────────────┘
```

### 규칙

| 항목 | 내용 |
|------|------|
| 영상 목록 | `playlistItems.list`(1 unit). **`search.list` 금지**(100 units) |
| 쇼츠 | 길이 60초 이하는 기본 해제. 자막이 짧아 상호 누락이 많다 |
| 여행/맛집 판정 | 제목·설명 1차, 애매하면 LLM. 제외된 것도 목록엔 보이되 해제 상태 |
| 도시 지정 | 조각 단위가 채널×도시이므로 넣을 때 정한다. 한 영상이 여러 도시면 나중에 후보별로 조정 |
| 진행 표시 | 단계별로. 자막 추출이 제일 오래 걸리고 실패도 잦아 개별 표시 |
| 요청 간격 | 2~3초 딜레이 (`INGEST.md` 2장 ③) |

### 실패 처리

| 실패 | 화면 동작 |
|------|-----------|
| 자막 없음/추출 실패 | 해당 영상만 ⚠️ 표시하고 계속. **재시도 버튼 제공(자동 재시도 안 함)**. 수동으로 장소 직접 추가하는 경로 제공 |
| LLM 분석 실패 | 1회 자동 재시도 → 실패 시 수동 입력 |
| 후보 0건 | "추출된 장소가 없습니다" + 수동 추가 버튼. 실패가 아니라 정상 결과일 수 있음 |

```
│               │  │ 1  마루시치 스미요시점                   ││

│               │  │    주오구 긴자 4-5-6                    ││

│               │  │    다이토구 우에노 7-8-9                 ││
│               │  └────────────────────────────────────────┘│

│               │                                            │

│               │  [자막에 "고토구" 언급 (12:31)          ]  │
│               │   ↑ 자동 채움. 수정 가능                    │
│               │                                            │

└──────────────┴─────────────────────────────────────────────┘
```

### 키맵

| 키 | 동작 |
|----|------|
| `1`~`5` | 해당 지도 후보로 **확정** → 자동으로 다음 후보 |
| `C` | **보류**(candidate) → 다음. 위치 미확정이지만 장소는 실재 |
| `X` | **버림** → 다음. 오탐이므로 저장하지 않음 |
| `←` `→` | 이전/다음 후보 (판정 없이 이동) |
| `E` | 근거 입력란 포커스 |
| `M` | 지도 후보를 못 찾겠을 때 — 직접 검색 입력 열기 |
| `?` | 단축키 도움말 |
| `Esc` | 입력란에서 빠져나오기 |

### ★ 확정 잠금 규칙 (오확정 방지)

이 프로젝트 유일한 구조적 리스크가 동명이점 오확정이다(`LEGAL.md` 4.6). 화면이 구조적으로 막는다.

```
지도 후보 1개 + 확신도 high   → 확정 허용 (★추천 표시)
지도 후보 2개 이상            → 확정은 가능하되 근거 입력이 비면 버튼 비활성
체인/동명이점 감지            → 지점명이 구분되지 않으면 확정 버튼 자체를 잠금
                                 (보류 C 만 허용)
```

- **근거 입력 없이는 확정 불가.** 자막에서 지역 언급을 찾으면 자동으로 채워주되, 없으면 직접 써야 한다.
- 체인 감지는 후보들의 이름이 같고 주소만 다른 경우로 판단한다.

### 자막 표시 규칙

| 규칙 | 이유 |
|------|------|
| 현재 후보 **주변 ±30초만** 표시 | 전문을 띄울 이유가 없다 |
| 세션 메모리에만 유지, 페이지 이탈 시 소멸 | DB 저장 금지(`LEGAL.md` 3.3) |
| `🔒 저장하지 않음` 뱃지 상시 표시 | 실수로 저장 기능을 붙이지 않도록 하는 시각적 방어 |
| 복사 버튼 없음 | 요약문에 복붙하는 경로를 원천 차단 |

```
┌────────────────────────────────────────────────────────────┐
│ ← 조각으로            돈카츠 마루시치          5 / 12       │
├────────────────────────────────────────────────────────────┤

│                                                            │

│  1 [돈카츠 전문점                                    ] ⊗   │

│  [+ 불릿 추가]                                             │
│                                                            │
│ 가격 정보                                                   │
│  [로스카츠 2,000엔대                                  ]    │
│  ⚠️ "영상 촬영 시점(2026-06) 기준" 이 자동으로 붙습니다      │
│                                                            │
│ ⚠️ 검사 결과                                                │
│  ✔ 글자수 87자 (40~200)                                    │
│  ✔ 금지어 없음                                              │
│  ⚠ 자막과 14자 연속 일치 — 불릿 3 확인 필요                 │
│                                                            │
│              [이전]  [저장 후 다음 →]                       │
└────────────────────────────────────────────────────────────┘
```

### 검사 (저장 전 자동)

| 검사 | 기준 | 실패 시 |
|------|------|---------|
| 글자수 | 40~200자 | 경고 |
| 불릿 수 | 3~5개 | 경고 |
| 금지어 | `진짜 미쳤 인생 존맛 대박 JMT` 등 | 경고 |
| **자막 복붙 감지** | 자막과 **12자 이상 연속 일치** | 경고 + 해당 불릿 표시 |
| 평가 표현 | `맛있 맛없 불친절 별로` | 경고 — 명예훼손 리스크(`LEGAL.md` 4.6) |

전부 **경고**이지 차단이 아니다. 판단은 사람이 한다. 다만 경고가 남은 채로는 `/admin/publish` 체크리스트를 통과하지 못한다.

가격·영업 정보에는 **"영상 촬영 시점 기준"** 이 자동으로 붙는다. 오정보 리스크 완화(`LEGAL.md` 4.6).

## 7. `/admin/publish` — 조각 공개 체크리스트

조각(채널×도시) 단위. **전부 통과해야 공개 버튼이 활성된다.**

```
┌────────────────────────────────────────────────────────────┐
│ 추성훈 × 도쿄                                               │
├────────────────────────────────────────────────────────────┤
│ ✔ 확정 핀 12개              (8개 이상)                      │
│ ✔ 소스 영상 2개             (2개 이상)                      │
│ ✔ 타입 다양성               맛집 8 · 명소 3 · 카페 1        │
│ ✔ 전 장소 출처 영상 연결     12/12                          │
│ ✔ 타임스탬프                 10/12 (83% ≥ 70%)             │
│ ✔ 전 장소 요약 작성          12/12                          │
│ ✘ 요약 경고 미해결           1건  → [보러 가기]              │
│ ✔ 도시 인트로 작성                                          │
│ ✔ confirmed 전부 좌표 보유   12/12                          │
│ ✔ candidate 비율            2/14 (14% ≤ 30%)               │
├────────────────────────────────────────────────────────────┤
│              [공개하기]  ← 비활성 (미충족 1건)               │
└────────────────────────────────────────────────────────────┘
```

기준 출처는 `CONCEPT.md` 7.1(조각 완성 정의).

> **요약 작성은 품질 기준이 아니라 법적 요건이다.** 요약이 비면 YouTube API §III.G.1.d(광고 게재 시 독립적 가치 요건)와 AdSense "스크랩된 콘텐츠" 판정에 걸린다(`LEGAL.md` 4.5).

공개 시 동작:
1. 해당 `places.is_published = true`
2. `creator_cities.published_at = now()`
3. `creators.is_published = true` (최초 조각일 때)
4. 통계 캐시 재계산 (`place_count` / `city_count` / `video_count`)
5. `revalidatePath` — 해당 채널·도시·장소 페이지만. **전체 재빌드 금지**

## 8. `/admin/queue` — 삭제 요청 · 수요

두 탭.

### 8.1 삭제·정정 요청 — 법정 절차다

```
┌────────────────────────────────────────────────────────────┐
│ [삭제 요청 2] [검색 수요]                                    │
├────────────────────────────────────────────────────────────┤
│ ● 접수  2026-08-04  place / 돈카츠 마루시치                 │
│   "폐업했습니다"                    from: owner@example.com │
│   [즉시 비공개] [해결 처리] [반려]                           │
│                                                            │
│ ● 임시조치 중  2026-07-28  creator / 추성훈                 │
│   "채널 전체 내려주세요"                                     │
│   ⏳ 30일 기한까지 24일 남음                                 │
│   [채널 전체 비공개] [해결 처리]                             │
└────────────────────────────────────────────────────────────┘
```

| 규칙 | 근거 |
|------|------|
| **선(先)비공개 후(後)검토** | 정보통신망법 §44조의3 — 신고 없이도 선제 블라인드 가능 |
| 임시조치 **30일 내** 결론 | §44조의2④ |
| 신청인·게재자 **양쪽 통지** | §44조의2② |
| 채널 단위 즉시 전체 비공개 | `creators.is_published = false` 하나로 RLS가 즉시 차단 |

기한이 지난 건은 목록 상단에 빨간색으로 고정한다. 상세는 `LEGAL.md` 4.7.

### 8.2 검색 수요

`search_misses` 를 count 내림차순으로. **다음에 만들 조각의 우선순위 데이터**다(`CONCEPT.md` 7.4 Batch 2 산식).

## 9. 공통 UI 규칙

| 항목 | 규칙 |
|------|------|
| 레이아웃 | 데스크톱 전용. 모바일 대응 안 함 — 확정 작업은 키보드가 필요하다 |

| 에러 | **자동 재시도 안 함**(요청 빈도 상한 유지). 수동 재시도 버튼만 |
| `noindex` | 전 페이지 |

## 10. 구현 순서

1. **인증** — 로그인 + proxy 보호 (전부의 전제)
2. `/admin` 대시보드 — 껍데기 + 집계 쿼리
3. `/admin/confirm` — ★ 가장 중요. 파이프라인 없이 **수동 입력만으로 먼저** 동작시킨다
4. `/admin/place/[id]` — 요약 에디터 + 검사
5. `/admin/publish` — 체크리스트
6. `/admin/ingest` — 파이프라인 연결 (`INGEST.md`)
7. `/admin/queue`

> **3번을 파이프라인보다 먼저 만드는 이유**: 자동 추출이 없어도 손으로 장소를 넣어 Batch 0(12핀)을 만들 수 있다. 그러면 웹뷰에 띄울 실데이터가 생기고, 어드민에 뭐가 더 필요한지도 실제로 써보고 알게 된다.
