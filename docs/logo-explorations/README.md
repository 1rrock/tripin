## 채택 (현재 코드)

| 안 | 용도 | 코드 |
|---|---|---|
| **Slash coral** | 파비콘·앱 아이콘·헤더 마크 | `src/shared/ui/Mark.tsx` · `src/app/icon.svg` · `apple-icon.tsx` · `public/mark.svg` |
| **Wax wordmark** | 헤더 워드 · EA**T**RI**P**IN | `src/shared/ui/Wordmark.tsx` · `public/wordmark.svg` |

- 마크: 왁스 면(`#c9441a`) + 잉크 슬래시(`#2a2118`). 콘택트 시트 **표시 한 획**.
- 슬래시: 광학 −45°, stroke 68, 끝단 inset (square cap 이 모서리에 안 붙게).
- 워드: Archivo 트래킹 캡스, 공유 T·P 만 왁스.
- 탐색 시트(미채택): `slash-coral.html` · `eat-type-tight*.html` 등.

문장 중 브랜드명: **Eatripin**. 워드마크 철자: **EATRIPIN** (t·p 각 1).

```
eat + trip + pin  →  EATRIPIN
```
