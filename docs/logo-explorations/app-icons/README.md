# EAT app icon samples

웹 워드마크 **EATRIPIN** 은 그대로 두고, **앱 아이콘만** 시안.

## 왜 EAT인가

- 이전 **ET** 모노그램 → 영화 E.T. 연상
- **EAT** = 브랜드 첫 덩어리 (`eat` + trip + pin) · 음식/여행 맥락과도 맞음
- 공유 접힘 글자 **T** 를 왁스로 살리면 워드마크 장치와 연결

## 보기

```bash
open docs/logo-explorations/app-icons/sheet.html
```
