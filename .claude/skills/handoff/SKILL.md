`docs/HANDOFF.md` 를 **현재 세션이 끝난 시점의 상태로** 갱신한다.
다음 세션이 이 파일 하나만 읽고 이어서 일할 수 있어야 한다.

추가 지시가 있으면 그쪽을 우선한다: $ARGUMENTS

## 먼저 사실을 모은다 (기억으로 쓰지 말 것)

```bash
git log --oneline -20
git status --short
npx tsc --noEmit 2>&1 | tail -5
```

## 담을 것

1. **30초 요약** — 지금 어디까지 왔나. 5줄 이내.
2. **이번 세션에 바뀐 것** — 커밋 해시와 함께. 무엇을 왜 바꿨는지.
3. **열린 것** — 🔴/🟡/🟢 우선순위. 각 항목에:
   - 지금 정확히 어떤 상태인가 ("구현됨, 미가동" 같이)
   - 막고 있는 게 무엇인가 (키? 콘솔 작업? 판단?)
   - **누가** 해야 하나 (사용자만 할 수 있는 일인지)
4. **되풀이하면 안 되는 실수** — 이번에 실제로 한 것만. 가정하지 말 것.
   이게 핸드오프에서 가장 값이 크다. 다음 세션이 같은 벽에 두 번 부딪히지 않는다.
5. **검증 명령** — 복붙해서 바로 돌릴 수 있는 형태로.
6. **다음 사람이 먼저 할 일** — 3개 이내.

## 규칙

- **낡은 문서를 그대로 두지 말 것.** 지금 코드에 없는 것을 기술하는 문서는 삭제하거나
  폐기 배너를 단다. 남겨 두면 다음 세션이 없는 것을 찾는다.
- **추측을 사실처럼 쓰지 말 것.** 확인 못 한 건 "미확인"이라고 적는다.
- 리포지토리를 읽으면 알 수 있는 것(디렉터리 구조, 의존성)은 넣지 않는다.
  넣을 것은 **코드만 봐서는 모르는 것** — 왜 그렇게 했는지, 무엇을 시도했다가 실패했는지.
- 다 쓰면 커밋한다.

## 마지막에

세션을 넘길 준비가 됐으면 사용자에게 알린다:

> 핸드오프 갱신 완료. 새 세션에서는 `docs/HANDOFF.md` 부터 읽습니다 (CLAUDE.md 가 그렇게 지시).
> 이어서 하려면 `claude -c`, 특정 세션을 고르려면 `claude -r`.
