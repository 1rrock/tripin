# Tripin

여행 유튜버(크리에이터)가 다녀간 곳을 **채널 단위로 모아 지도에 보여주는** 웹 서비스.

> 가칭 브랜드: **Tripin** (trip + pin)  
> 부제(KR): 여행 유튜버가 간 곳 지도  
> 부제(EN): Map places from travel YouTubers  
> 작성: 2026-08-01 · 히든스팟 논의에서 파생 · **구현 전 기획 전달용**

---

## 1. 한 줄 포지션

**유튜버를 고르면, 그 사람이 전 세계에서 간 곳(맛집·명소 등)이 지도에 뜬다.**  
신뢰는 앱 자체 큐레이션이 아니라 **이미 구독하는 크리에이터**에 기대고, 공개 단위는 **장소 + 영상 링크 + (가능하면) 지도 플레이스**다.

---

## 2. 왜 만드는가 (히든스팟과의 관계)

| | 히든스팟 | Tripin |
|--|----------|--------|
| 신뢰 원천 | 제보·공식 큐레이터 (혼자 품질 한계) | 크리에이터 브랜드 |
| 설명 | “숨은 곳” — 추상적 | “○○ 유튜버 간 곳” — 검색·공유 쉬움 |
| 재고 문제 | 맵온 맛집 핀 과다, 나무위키 톤 | 채널×도시 **밀도**가 제품 |
| 사용 시점 | 저빈도 | 여행 전·중 (저빈도, 다만 의도 명확) |
| 현재 상태 | 앱인토스 등 진행 중 | **사이드 신규** (직장 병행) |

히든스팟에서 배운 것:

- 만들고 나서 포지션·신뢰 문제를 발견하지 말 것 → **검증 후 확장**
- 혼자 콘텐츠 품질 올리는 모델은 스케일 어려움
- 사이드는 **하나 메인**, 둘 다 풀로 잡지 말 것

## 3. 타깃 유저

1. **여행 직전** — 구독 채널(곽튜브, 빠니보틀, 추성훈, Kara and Nate 등) 기준으로 동선·맛집 보고 싶은 사람  
2. **성지순례** — 특정 영상/채널 팬  
3. (확장) 영어권 등 **글로벌 여행 유튜버** 팬 — EN UI + 글로벌 채널

**비타깃:** 매일 여는 소셜 앱, “내 주변 오늘 저녁” 전용 (그건 튜브맵류).

## 4. 경쟁·시장

### 4.1 한국

| 서비스 | 내용 | 겹침 |
|--------|------|------|
| 튜브맵, 유튜브 플레이스, 먹방로드 등 | **국내** 유튜브·방송 **맛집** 지도 | 낮음 (글로벌 여행 채널·명소 아님) |

### 4.2 글로벌

| 유형 | 예 | 차이 |
|------|-----|------|
| 숏폼 → **내** 지도 저장 | Plotline, Stasht, JoySpot, Omniteca… | 개인 저장. 채널 전체 디렉터리 아님 |
| 장소 수첩 | Mapstr | 수동 위주 |
| 여행 플래너 | Wanderlog | 일정·예약 |
| 방문 국가 트래커 | been, Visited | 내 기록 |
| 인디 유튜브 먹방 맵 | Reddit 등 소규모 | 채널 퍼스트 글로벌 여행 인덱스는 드묾 |

**결론:**  
“**채널 선택 → 글로벌 발자국 지도 + 플레이스 확정**” 완성형 메이저는 거의 없음.  
공백 이유 ≈ **불법 단독이 아니라 노가다 원가 + 저빈도 + AdSense 단가** 때문에 큰 돈이 안 몰림.

## 5. 핵심 제품 원칙

1. **채널 퍼스트** — 홈 = 크리에이터 목록 → 채널 맵/리스트  
2. **장소는 플레이스 우선** — 가능하면 Google/Kakao 등 **place id** (식당 카드로 열기). 좌표만은 최후 수단  
3. **미확인은 미확인** — 억지 핀 금지  
4. **출처 필수** — YouTube `videoId` / URL. 공식 제휴 아님 고지  
5. **자막 전문 비공개** — 추출은 내부 후보용, DB·UI에 원문 저장·노출 금지  
6. **요약은 짧게·직접 작성** — 대사 복붙·긴 줄거리 재서술 금지  
7. **완성형 조각** — 얇은 전 세계보다 **채널×도시 하나를 꽉** 채우기  
8. **웹 먼저** — SEO + AdSense. 앱/앱인토스는 후순위

## 6. 데이터 파이프라인 (합의된 운영)

```
YouTube URL (또는 채널 영상 목록)
    → 자막/설명 등에서 장소·식당 후보 추출 (자동화, 내부)
    → 자막 원문은 저장하지 않거나 처리 후 폐기
    → 지도/플레이스 검색으로 후보 좌표·place id
    → 사람 확인: 확정 / 수정 / 미확인·없음
    → 짧은 요약문 작성 (팩트만, 티 나게 복붙하지 않되 출처는 숨기지 않음)
    → 공개
```

### 6.1 자동으로 되는 것

- 채널 영상 목록 (RSS / YouTube Data API 메타)  
- 공개 자막 수신 (기술 가능 — 예: 추성훈 채널 본편에서 상호·지역 추출 실험함)  
- 가게명·도시 힌트 → Places 검색 후보  

### 6.2 사람이 하는 것

- 동명이점·체인 지점 선택  
- 플레이스 최종 확정  
- 요약 톤·사실 검수  
- 맵에 없는 뷰포인트 등 좌표/미확인 처리  

### 6.3 기술 실험 메모 (2026-08)

- 채널 예: `https://www.youtube.com/@Choosunghoon_ajossi`  
  - channelId: `UCMDHzyo0wIUjKXho-icJDjw`  
- 본편 예: 워뇨 추천 도쿄 돈카츠 → 자막에서 **돈카츠 마루시치**, **도쿄 고토구**, 가격·웨이팅 등 힌트 추출 성공  
- 쇼츠는 자막이 짧아 상호 누락 많음 → **본편 우선**

## 7. 법률·정책 (요약 — 법률 자문 아님)

| 행위 | 리스크 |
|------|--------|
| 자막 전문 DB·화면 게시 | 높음 — 하지 말 것 |
| 비공식 자막 API로 대량 추출 | YouTube ToS 회색 — 내부 최소·미게시 |
| 공식 captions.download | 남의 영상 대량용 아님 |
| 장소명 + 영상 링크 + 짧은 자체 요약 + 지도 | 상대적으로 낮음 (사실·링크 중심) |
| 출처 표기 | 도움 됨. 위반을 합법으로 바꾸진 않음 |
| 유튜버 이메일 무응답 | **허락 아님** |
| 삭제 요청 | 즉시 삭제 정책 필수 |
| “튜브맵 있으니까 OK” | 시장 참고일 뿐 법적 면책 아님 |

**공개 라인 (권장):**  
내부 도구로 후보만 → 사람 확정 → 팩트 요약 + 링크 + place.  
“티 안 나게” = 대사 복붙 안 함. **출처 숨기기가 아님.**

## 9. UX 초안

### 웹

1. **홈** — 크리에이터 그리드 (국가/언어 필터)  
2. **크리에이터** — 세계 지도 + 리스트, 국가·도시 필터  
3. **장소 상세** — 이름, 짧은 요약, 지도/플레이스 열기, **언급 영상 목록(링크)**  
4. **도시 랜딩 (SEO)** — `/c/kwaktube/tokyo` 식  
5. 고지 — 비공식 디렉터리, 제휴 아님, 삭제 요청  

### 딥링크

- Google: `place_id` 기반 Maps URL  
- 국내: 카카오/네이버 place (정책·키 확인)  
- 플레이스 없으면 좌표 또는 “위치 미확인”

## 13. MVP / 검증 (만들기 전·직후)

### Phase 0 — 검증 (1~2주, 풀앱 금지)

1. 랜딩 1장 + 대기 메일 또는  
2. **크리에이터 1 × 도시 1** 진짜 지도 (핀 확정 + 영상 링크)  
3. 공유 후: 저장·공유·“다른 채널도” 요청 측정  

Go 신호 예: 대기/관심 행동, 재방문, 구체 요청.  
No: “검색하면 되는데?” 만 나오고 행동 없음.

### Phase 1 — MVP

- 크리에이터 3~5 (예: 한국어 해외 여행 채널 위주)  
- 채널당 도시 1~2 **완성형**  
- 웹, AdSense 신청  
- 등록 UI는 관리자/스크립트 수준이면 충분  

### Phase 2+

- 채널·도시 확장  
- EN UI + 영어권 크리에이터  
- place 검색 UX 개선  
- (선택) 앱  

**비권장 초반:** 앱인토스 1차, 전 세계 채널 얇게 뿌리기, 자막 공개 아카이브.
